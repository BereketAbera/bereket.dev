## Overview

> I build complex web interfaces and carry them through to production. If you have a data-heavy screen, a multi-step workflow, or a feature nobody has fully specified yet, that is the work I do best.
>
> For the last three years I have worked at Acelab on a large Vue and Nuxt product for architects and manufacturers. I owned the frontend of a workflow that lets architects request product data from manufacturers, I built how cell edits are saved and single-cell undo and redo for a spreadsheet-style editor whose grid teammates built, and I built a public Chrome extension. Since June 2026 I also build the .NET endpoints and SQL behind my features, inside services teammates built and run.
>
> What you can hire me for:
>
> - Complex frontend features in Vue, Nuxt, React or Next.js: dense data, autosave, real-time updates, multi-step flows.
> - Design systems and reusable component libraries.
> - Full-stack features, from the interface through the API and database.
> - Deployment and CI/CD at small-team scale: Docker, Kubernetes (K3s), GitHub Actions, monitoring and backups.
>
> I use AI coding tools in my development every day, and I review and test what I deliver. I work remotely from Addis Ababa (UTC+3), and I tell you plainly what has and has not been tested. Tell me what you want to build and when you need it, and I will say whether it is a good fit.
